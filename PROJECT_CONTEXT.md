# Lucky Ramadhan — Personal Portfolio Project

> Update pengguna, 13 September 2026: gunakan UI Figma saat ini, tetapi tanpa karakter manusia untuk sementara. Ini menggantikan kebutuhan artwork karakter pada fase sementara ini. Layer karakter pada delapan screen prototype aktif (Main Menu, About, Experience, Projects, Skills, Achievements, Contact, The Lab), termasuk potret kecil dan thumbnail About, sudah disembunyikan di Figma agar dapat dipulihkan. Versi studi lama tetap tersimpan. Main Menu aktif: https://www.figma.com/design/n6Gi5Hx54vlBSV3T25HXUm?node-id=28-2 . Data placeholder pada UI tetap belum menjadi fakta terkonfirmasi.

## 1. Tujuan

Membuat **personal portfolio website** yang tidak terasa seperti website portfolio konvensional. Portfolio dirancang sebagai pengalaman interaktif bergaya **game menu**, dengan Persona 3 Reload sebagai benchmark utama untuk visual language, composition, navigation, dan transisi.

Untuk fase prototype saat ini, keputusan kita adalah mengejar **fidelity sedekat mungkin dengan UI P3R** terlebih dahulu. Setelah konsep dan experience-nya berhasil, desain dapat dibuat lebih original jika nantinya diperlukan untuk versi publik.

Target utama:

> **Portfolio yang terasa seperti membuka menu dalam sebuah game, bukan scrolling sebuah landing page.**

---

## 2. Design Direction

Benchmark utama adalah UI **Persona 3 Reload**.

Karakter visual yang sudah kita lock:

- dominan blue / cyan / deep navy
- area putih dengan kontras ekstrem
- aksen merah untuk selected state
- diagonal/angular composition
- typography sangat besar
- asymmetric layout
- underwater / water-like visual language
- glass/reflection/shimmer
- layered interface
- anime character sebagai bagian utama komposisi
- oversized background typography
- game-like navigation dan controller hints
- animasi/transisi menjadi bagian penting dari experience

Jadi bukan sekadar:

> “website berwarna biru yang terinspirasi Persona.”

Tetapi mencoba memahami struktur visual dan interaction language P3R.

---

# 3. Struktur Portfolio

Navigation utama yang sekarang kita gunakan:

**ABOUT → EXPERIENCE → PROJECTS → SKILLS → ACHIEVEMENTS → CONTACT**

Desktop dirancang sebagai **full-screen experience 16:9**, bukan long scrolling page tradisional.

Setiap menu akan menjadi screen sendiri dengan artwork, layout, informasi, dan transition sendiri.

Input nantinya dapat mendukung:

`Mouse / Click`  
`W / S` atau `Arrow Keys`  
`Enter → Confirm`  
`Escape → Back`

# 5. Character Art System

Keputusan penting berikutnya adalah:

> **Setiap menu mempunyai artwork karakter sendiri.**

Tetapi semuanya harus terlihat sebagai **orang/karakter yang sama**.

Yang berubah adalah pose, environment, props, dan storytelling berdasarkan menu.

Dengan begitu artwork bukan dekorasi, tetapi membantu menjelaskan section.

# 7. EXPERIENCE

Konsep:

> **Past Shapes Present.**

Experience tidak hanya dimaksudkan sebagai daftar pekerjaan seperti CV.

Screen menggunakan **professional journey/timeline**, sehingga nantinya bisa mencakup:

- Work
- Hackathon
- Project/Initiative
- Organization/community bila relevan

Character digambarkan sedang bergerak/berjalan sehingga secara visual menyampaikan perjalanan.

Informasi bisa berupa:

`YEAR → ROLE → ORGANIZATION → DESCRIPTION → TECHNOLOGY`

Catatan penting: detail pekerjaan seperti jabatan dan tanggal **tidak boleh diinventarisasi dari asumsi**; data final perlu berasal dari informasi sebenarnya.

Jadi generated artwork **bukan menggantikan Figma**.

---

# 14. Motion Direction

Motion merupakan bagian penting dari fidelity.

Setiap screen nantinya perlu memikirkan state:

**Idle → Hover → Selected → Confirm → Transition → Screen Open → Back**

Contohnya ketika memilih `PROJECTS`:

menu item bergerak/menonjol → red accent muncul → background/character bergeser → blue-water transition mengambil layar → Projects screen terbentuk.

Jadi character artwork dan UI sebaiknya berada pada layer berbeda agar bisa dianimasikan secara independen.

---

# 15. Prinsip Penting untuk Implementasi

Ada tiga layer yang sebaiknya selalu kita pisahkan:

**CONTENT**

Data asli Lucky: experience, projects, skills, achievement, contact.

**UI**

Menu, typography, card, navigation, HUD, stats, timeline.

**ART**

Character, environment, water effects, city abstraction, decorative illustrations.

Pemisahan ini akan membuat website jauh lebih mudah dianimasikan dan dipelihara.
